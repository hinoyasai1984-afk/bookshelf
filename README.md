# 本棚

自作の読書アプリ(ブック)をまとめた、書架レイアウトの一覧ページ。背表紙をタップするとその本(=別リポジトリで公開している読書アプリ)を開く。

公開: https://hinoyasai1984-afk.github.io/bookshelf/

## 本を追加する方法

新しく読書アプリを作ったら、`app.js` 冒頭の `books` 配列に1件追加するだけでよい。

```js
{
  id: "スラッグ",
  title: "本のタイトル",
  subtitle: "副題(任意)",
  url: "https://hinoyasai1984-afk.github.io/リポジトリ名/",
  category: "ジャンル(例: 思想史)",
  description: "1文の紹介文",
  color: "#ライトテーマ時の背表紙色",
  colorDark: "#ダークテーマ時の背表紙色"
}
```

背表紙の幅・高さ・わずかな傾きはタイトル文字列から自動計算されるので、指定不要。7冊目以降は自動的に次の棚(行)に折り返される。

ビルド不要の静的サイト。`index.html` / `style.css` / `app.js` のみで構成。
